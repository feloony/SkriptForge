# SkriptForge

A ready-to-use **Minecraft 1.8.8** server pack for Skript development, server configuration, and gameplay experimentation.

> Community-made resource. Not affiliated with Mojang Studios or Microsoft.

## ✨ What's Included

- 🧩 Skript environment
- ⛏️ Minecraft Java Edition 1.8.8 setup
- 📦 Server configuration and resources
- 📝 Skript scripts
- ⚙️ Server properties and configuration
- 🛠️ A practical base for custom server development

## 🚀 Quick Start

```bash
git clone https://github.com/feloony/SkriptForge.git
cd SkriptForge
```

Prepare the server files in a dedicated directory and use a Java runtime compatible with your 1.8.8 server software.

If the pack contains an EULA file, only set `eula=true` after reading and agreeing to Minecraft's EULA.

```bash
java -Xms1G -Xmx2G -jar server.jar nogui
```

## 🧩 Skript

Scripts are normally stored under:

```text
plugins/Skript/scripts/
```

Reload scripts using the appropriate command for the installed Skript version.

Minecraft 1.8.8 is an old server target. Verify that additional plugins and dependencies support your exact server software before installing them. Avoid blindly replacing included versions.
